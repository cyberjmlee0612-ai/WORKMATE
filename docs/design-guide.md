# WORKMATE UI/UX 디자인 가이드

## 1. 목적과 적용 범위

이 문서는 WORKMATE 화면에 공통으로 적용할 시각·상호작용 기준을 정의한다. 서비스 기능과 개발 범위는 [서비스 기획서](planning.md), 대시보드의 정보 구조와 동작은 [화면 설계서](screen-specification.md)를 기준으로 한다. 이 문서의 색상, 글꼴, 크기, 간격 및 효과 수치는 **초기 디자인 토큰 제안값**이며 실제 화면 검증 후 변경할 수 있다. 문서에 적힌 효과나 기능이 현재 코드에 구현되었다는 뜻은 아니다.

## 2. 브랜드와 디자인 콘셉트

- **서비스:** AI 기반 프로젝트 및 업무 관리 SaaS WORKMATE
- **핵심 가치:** 정리, 실행, 성장
- **콘셉트:** Soft Glass × Liquid Accent
- **인상:** 깔끔하고 전문적이면서 차갑지 않은 프리미엄 미니멀 디자인
- **우선순위:** 업무 정보의 선명도와 빠른 탐색을 먼저 확보하고, 글래스 효과는 깊이와 집중을 돕는 범위에서 사용한다.

기본 화면은 웜 아이보리 배경과 차분한 딥그린 텍스트·동작색을 사용한다. 반투명 표면은 카드의 계층을 표현하고, 굴곡과 반사광이 있는 리퀴드 글래스는 AI 도우미와 같은 소수의 강조 영역에만 사용한다.

## 3. 색상 팔레트

| 토큰 | 초기 값 | 역할과 사용 위치 |
| --- | --- | --- |
| Primary Dark Green | `#244C3B` | 제목, 주요 텍스트 강조, 선택 메뉴, 강한 동작 |
| Primary Green | `#356B52` | 기본 버튼, 진행 상태, 링크 및 활성 표시 |
| Pale Green | `#E7F0EA` | 선택·호버 배경, 약한 성공 상태 |
| Sage Green | `#8FAF9B` | 보조 강조, 차트 및 진행 막대의 보조색 |
| Soft Sage | `#C7D8CA` | 장식 면, 구분 면, 부드러운 포인트 |
| Warm Ivory | `#F8F8F5` | 앱의 기본 배경 |
| White | `#FFFFFF` | 카드·입력면 및 선명도가 필요한 표면 |
| Border | `#E7E9E5` | 카드·입력면·구분선의 기본 테두리 |
| Text | `#303B35` | 본문과 업무 정보 |

색상값은 **확정된 최종 팔레트가 아닌 초기 기준**이다. 본문은 Warm Ivory 또는 White 위에 Text를 우선 사용한다. Primary Green은 클릭 가능한 요소와 진행 상태에 집중하고, Sage 계열만으로 중요한 텍스트를 표현하지 않는다. 오류·경고·정보 상태의 전용 색은 아직 정해지지 않았으므로 구현 전 별도 정의가 필요하다. 상태는 색만으로 전달하지 않고 텍스트·아이콘을 함께 둔다.

## 4. 글꼴과 타이포그래피

한글 기본 글꼴은 **Pretendard**, 영문 및 숫자 보조 글꼴은 **Geist**, 코드 및 개발 정보에는 **Geist Mono**를 사용한다. 제목 굵기는 600–700, 본문 굵기는 400–500, 기본 본문 크기는 14–16px을 기준으로 한다. 현재 코드의 `layout.tsx`는 Geist·Geist Mono를 불러오고 `globals.css`의 본문은 Arial 계열을 지정한다. Pretendard 적용이나 패키지 설치는 아직 이루어지지 않았다.

| 용도 | 초기 크기 / 줄 높이 | 굵기 | 원칙 |
| --- | --- | --- | --- |
| 화면 제목 | 28–32px / 1.3 | 600–700 | 한 화면에 한 개의 최상위 제목 |
| 영역 제목 | 18–20px / 1.4 | 600–700 | 카드·목록의 시작점 표시 |
| 카드 지표 | 28–32px / 1.2 | 700 | 숫자와 단위를 함께 읽을 수 있게 배치 |
| 본문·업무명 | 14–16px / 1.5 | 400–500 | 긴 업무명은 줄바꿈 허용 |
| 보조 정보 | 12–14px / 1.4 | 400–500 | 마감일·설명·메타데이터 |

크기와 굵기는 초기 기준이다. 작은 글씨, 연한 색, 반투명 배경을 동시에 적용하지 않는다. 지표 숫자는 자리수 변화에도 정렬이 안정적이어야 한다.

## 5. 여백, 간격, 정렬

- 기본 간격 단위는 **4px**로 제안한다. 자주 쓰는 간격은 8·12·16·24·32px로 제한한다.
- 데스크톱 본문 바깥 여백은 32–40px, 태블릿은 24px, 모바일은 16px을 초기 기준으로 한다.
- 카드 안쪽 여백은 데스크톱 24px, 태블릿 20px, 모바일 16px을 기준으로 한다. 카드 사이는 16–24px을 유지한다.
- 제목, 설명, 동작 버튼은 같은 수평 기준선에 맞추고 정보 그룹 사이의 간격을 그룹 내부보다 크게 둔다.
- 요약 지표와 프로젝트 정보는 왼쪽 정렬을 기본으로 하며 숫자와 단위의 관계가 명확해야 한다.

## 6. 버튼과 상태

| 유형 | 사용 위치 | 기본 표현 |
| --- | --- | --- |
| 주요 버튼 | 새 프로젝트, 빈 상태의 생성 동작 | Primary Green 배경, White 텍스트 |
| 보조 버튼 | 추가 탐색, 취소 | White 또는 Pale Green 배경, Primary Dark Green 텍스트, 얇은 테두리 |
| 아이콘 버튼 | 알림, 사이드바 접기, 모바일 탐색 | 충분한 누름 영역과 접근 가능한 이름 |

버튼은 기본·호버·키보드 포커스·눌림·비활성·처리 중 상태를 구분한다. 포커스 표시는 배경 효과와 무관하게 선명해야 한다. 비활성 상태는 색을 옅게 하는 것만으로 끝내지 않고 동작 불가 상태를 의미상으로도 표현한다. 기본 높이는 40–44px, 모서리 반경은 10–12px을 초기 기준으로 한다. 한 영역에서 동일한 강도의 주요 버튼을 여러 개 경쟁시키지 않는다.

## 7. 카드

요약 카드에는 지표명, 수치, 설명을 명확한 순서로 배치한다. 프로젝트 카드는 프로젝트명, 진행 상태, 완료/전체 업무 수, 진행률, 마감일을 읽기 쉽게 묶는다. 오늘의 업무는 가로형 목록 행으로 구성하며 체크박스와 제목을 가장 먼저 읽게 한다.

기본 카드의 초기 기준은 16–20px 모서리 반경, Border 색의 1px 테두리, 16–24px 내부 여백이다. 클릭 가능한 카드에는 호버·포커스 상태를 제공한다. 정보량이 많은 카드에 장식 반사광이나 강한 투명도를 적용하지 않는다.

## 8. 프로스트 글래스

사이드바 표면, 상단의 보조 패널, 요약 카드 등 **넓고 반복되는 표면**에 은은하게 적용한다. 초기 구현 검토 범위는 흰색 표면의 약 80–92% 불투명도와 12–20px 배경 블러다. 실제 값은 배경 위에서 텍스트 대비를 확인해 조정한다. 얇은 밝은 테두리와 낮은 그림자를 조합해 카드 경계를 만든다.

프로젝트명, 업무명, 수치, 입력 내용, 버튼 레이블은 선명한 전경색으로 유지한다. 복잡한 배경 위에 반투명 텍스트를 겹치지 않으며, 목록 전체를 겹겹의 글래스 패널로 만들지 않는다. 블러를 사용할 수 없는 환경에서도 불투명한 대체 배경으로 정보가 읽혀야 한다.

## 9. 리퀴드 글래스 포인트

AI 업무 도우미 진입 카드 또는 제한된 강조 요소에만 굴곡, 부드러운 색 번짐, 반사광을 적용한다. 강조 영역은 한 화면에서 시선을 빼앗지 않는 소수로 제한한다. 반사광은 텍스트·버튼·상태 배지의 뒤를 가로지르지 않게 배치한다.

업무 목록, 긴 설명, 입력 양식, 프로젝트의 핵심 수치에는 강한 왜곡·굴절을 적용하지 않는다. 동적 효과를 추가한다면 사용자의 움직임 감소 설정을 따르고, 정지된 상태에서도 의미가 전달되어야 한다.

## 10. 블러, 투명도, 테두리, 그림자

- **블러:** 표면의 배경에만 사용한다. 중요한 정보 자체를 흐리게 하지 않는다.
- **투명도:** 배경색과 콘텐츠의 대비를 먼저 확인한다. 글래스 배경이 불안정하면 White에 가까운 불투명 표면으로 전환한다.
- **테두리:** 기본 1px. 과도한 이중 테두리나 광택선은 강조 영역 외에는 피한다.
- **그림자:** 기본 카드는 낮고 넓은 그림자로 구분한다. 부유 효과가 필요한 대화창·메뉴에만 더 강한 그림자를 사용한다.
- **곡선:** 카드·버튼·배지의 반경 체계를 유지한다. 리퀴드 포인트의 비정형 곡선은 기본 컴포넌트 형태를 대체하지 않는다.

## 11. 아이콘과 상태 표시

아이콘 라이브러리는 **Lucide**로 통일하고 서로 다른 라이브러리나 스타일을 혼합하지 않는다. 기본 선 굵기는 2px, 기본 크기는 20px이다. 보조 아이콘은 16px, 주요 액션 아이콘은 20–24px을 기준으로 한다. 기본 색상은 Deep Green `#244C3B`, 보조 색상은 Green `#356B52`, 선택 배경은 Pale Green `#E7F0EA`를 사용한다.

아이콘은 의미가 명확하고 시각적 무게가 비슷해야 한다. AI 아이콘도 일반 Lucide 스타일을 유지하고 색상과 은은한 글래스 효과로만 강조한다. 메뉴에는 아이콘과 텍스트를 함께 사용하며 접힌 사이드바의 아이콘에는 툴팁과 접근 가능한 이름을 제공한다. 완료·진행 중·마감 임박·지연 등의 상태는 레이블과 아이콘·형태로 구분한다. Lucide는 **디자인 기준으로 확정되었으나 현재 코드에 설치·적용되지는 않았다.**

## 12. 반응형 디자인

- **데스크톱(1024px 이상):** 펼친 사이드바를 기본으로 하고 사용자가 접거나 펼칠 수 있다. 요약 지표는 4열이며 넓은 프로젝트 영역 아래 오늘의 업무 영역을 둔다. 콘텐츠 여백은 32–40px, 카드 내부 여백은 24px이다.
- **태블릿(768–1023px):** 사이드바가 자동으로 접힌다. 요약 지표는 2열이고 프로젝트·업무 정보는 세로 흐름에 맞게 줄바꿈한다. 콘텐츠 여백은 24px, 카드 내부 여백은 20px이다.
- **모바일(767px 이하):** 사이드바를 숨기고 하단 고정 메뉴 5개(홈, 프로젝트, 업무, AI, 더보기)를 제공한다. 더보기에는 캘린더·리포트·설정을 둔다. 요약 지표와 주요 영역은 1열이며 콘텐츠 여백은 16px, 카드 내부 여백은 16px이다. 업무 행의 보조 정보는 여러 줄로 배치하되 체크박스와 업무명은 유지한다.

모바일에서는 블러 효과를 줄여 성능과 가독성을 확보한다. 터치 영역은 최소 44×44px을 목표로 한다. 가로 스크롤, 텍스트 겹침, 버튼 잘림 없이 한국어 긴 제목과 큰 글씨 설정을 수용한다. 위 폭 기준은 v1.0 기준이며 실제 화면 검증 후 세부 배치를 조정할 수 있다.

## 13. 접근성과 가독성

- 일반 텍스트는 최소 **4.5:1**, 큰 텍스트는 **3:1** 명암비를 목표로 한다. 팔레트·글래스 조합별 실제 측정은 구현 단계에서 수행한다.
- 키보드로 메뉴, 버튼, 카드 동작, 체크박스에 접근하고 현재 포커스를 식별할 수 있어야 한다.
- 누름 영역은 최소 44×44px을 목표로 한다. 글자 확대 시 잘림이나 겹침이 없어야 한다.
- 마감 임박과 완료는 색만으로 알리지 않는다. 날짜·상태 텍스트를 함께 제공한다.
- 움직임과 블러가 읽기나 성능을 방해하면 효과를 줄인다.

- [ ] 4px 간격 체계와 공통 모서리 반경을 따르는가?
- [ ] 글래스 효과가 텍스트와 핵심 업무 정보를 흐리지 않는가?
- [ ] 리퀴드 효과가 소수의 강조 영역에만 있는가?
- [ ] 버튼과 클릭 가능한 카드에 호버·포커스·비활성 상태가 있는가?

## 15. 후속 확정 사항

Pretendard 파일 공급·적용 방식, 상태별 전용 색, 글래스 효과의 최종 수치와 화면별 세부 배치는 시안·접근성 검증 후 확정한다. 글꼴 역할, Lucide 아이콘 체계와 반응형 폭 기준은 v1.0 기준으로 확정했다. 현재 프런트엔드는 Tailwind CSS 유틸리티를 사용한다. Lucide는 아직 설치·적용되지 않았으며, 기획서에 shadcn/ui가 기술 스택으로 언급되어 있으나 현재 설치·사용은 확인되지 않았다.
