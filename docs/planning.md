
# WORKMATE 서비스 기획서

## 1. 프로젝트 소개

- 서비스명: WORKMATE
- 서비스 유형: AI 기반 프로젝트 및 업무 관리 웹 서비스
- 개발 목적: 개인 포트폴리오 제작 및 실제 사용 가능한 서비스 구현

## 2. 서비스 개발 목표

사용자가 자연어로 업무를 입력하면 AI가 업무를 분석하고,
세부 작업과 우선순위, 예상 소요 시간을 제안하는 서비스를 만든다.

사용자는 AI의 제안을 확인하고 수정한 후 최종 승인하여 저장할 수 있다.

## 3. 핵심 기능

### 3-1. 회원 관리
- 회원가입
- 로그인 및 로그아웃

### 3-2. 프로젝트 관리
- 프로젝트 생성
- 프로젝트 목록 조회
- 프로젝트 수정
- 프로젝트 삭제

### 3-3. 할 일 관리
- 할 일 생성 및 수정
- 할 일 삭제
- 진행 상태 관리
- 우선순위 설정
- 마감일 설정

### 3-4. AI 업무 관리
- 자연어 업무 입력
- 업무를 세부 작업으로 분리
- 우선순위 제안
- 예상 소요 시간 제안
- 하루 업무 계획 제안

### 3-5. 대시보드
- 전체 프로젝트 현황
- 진행 중인 업무
- 완료된 업무
- 마감 임박 업무

## 4. 기술 스택

- Frontend: Next.js, React, TypeScript
- UI: Tailwind CSS, shadcn/ui
- Backend: Python, FastAPI
- Database: Supabase PostgreSQL
- Authentication: Supabase Auth
- AI: LLM API
- Version Control: Git, GitHub
- Deployment: Vercel, Render

## 5. 개발 원칙

1. 기본적인 프로젝트 관리 기능부터 구현한다.
2. AI 기능은 기본 기능이 완성된 후 연결한다.
3. AI가 제안한 내용은 사용자가 확인하고 승인한 뒤 저장한다.
4. 사용자 데이터와 API 키를 안전하게 관리한다.
5. 실제 사용 가능한 수준으로 개발한다.
